# Articles Route

This route handles the display of articles and related content.

## Features
- List view of articles.
- Detailed view for individual articles.
- Data sourced from `articles.json`.

## Schema
Individual articles within this route follow the structure defined in `articles.json`:
- **href**: The external URL of the article.
- **title**: The title of the article.

## Examples
Example of an article entry:
