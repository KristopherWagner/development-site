# Amazon S3 Configuration

## Archive Bucket (lfc-archive-{account-id}-us-east-1-an)

**Purpose**: Immutable archive of original `.xlsm` spreadsheet files during and after migration. Serves as the permanent, versioned source of truth for historical data that must be preserved indefinitely without deletion or modification.

**Key Settings**:

- **Bucket Versioning**: Enabled
- **MFA Delete**: Disabled
- **Encryption**: SSE-S3 (Bucket Key: Disabled)
- **Block Public Access**: Off

## Results Bucket (lfc-results-{accountid}-us-east-1-an)

**Purpose**: Stores weekly results JSON files, season archives, and lifetime stats. Uses an overwrite/idempotent write pattern where latest results replace previous data each week; historical data is preserved in DynamoDB instead of S3.

**Key Settings**:

- **Bucket Versioning**: Disabled
- **MFA Delete**: Disabled
- **Encryption**: SSE-S3 with Bucket Key: Enabled
- **Block Public Access**: Off
